# n2

Neutron-2 mission website.

The page summarizes the public Neutron-2 mission:

- Two CubeSats in polar low Earth orbit
- Low-energy neutron and gamma-ray flux measurements
- Next-generation neutron detectors developed at ASU
- University Nanosatellite Program Cycle 12 / Phase A
- Shared launch with deployment to slightly different altitudes

## Local preview

Open `index.html` directly, or serve the repository locally:

```sh
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
